# Rimefall Milestone 2.1: OSRS-style combat rework (from playtest)

Playtest complaints on M2: wolves move exactly in sync with the player (you can never step off and back), wolf pathing is too smart (OSRS NPCs don't route around pillars), and the player dislikes lock-on. Rework combat per the exact spec below.

HARD CONSTRAINTS: do NOT change movement feel (1.2): tick.js, the camera, stick/keyboard direction mapping, snapping/hysteresis, the one-tile-per-tick linear lerp, corner sliding for walls/pillars. A movement regression suite (run with ?noenemies=1) must keep passing. Output the COMPLETE contents of every new or changed file (=== FILE === format).

## Player
1. REMOVE lock-on/targeting entirely: no target state, ring, chevron, cycle (Tab/R1/L1) or clear (Q/Circle). The HUD no longer shows a target. Health bars still appear above any enemy damaged in the last 10 ticks.
2. Facing: the player has an 8-way facing; moving sets facing. If the movement input points at a tile occupied by an ENEMY, the player turns to face that direction and does not move (no slide). If the input points at a wall/pillar: a cardinal just turns with no move; a corner-blocked diagonal keeps the existing 1.2 slide rule (slide candidates occupied by enemies count as blocked); if nothing is possible, just turn to the input direction. The mesh rotates to face (keep the existing smooth turn).
3. Facing indicator: a subtle, faint wedge/arrow on the floor tile in front of the player (the facing tile), readable but not loud (e.g. pale yellow, ~35% opacity). It snaps with the logical tile and facing.
4. Attack = ✕ (button 0) / Space, edge-triggered (a fresh press; holding does NOT repeat, and keyboard auto-repeat keydown events are ignored). A press made during tick interval T is evaluated at the next tick processing only:
   - If the weapon cooldown is ready that tick (tick >= nextAttackTick), the player attacks the FACING tile. Melee range is 1 and cardinal only: if the facing is diagonal, the swing goes to the diagonal tile and can never hit (whiff). If an enemy is on the (cardinal) facing tile, roll hit/damage as now. Otherwise it's a whiff. Either way the cooldown is consumed: nextAttackTick = tick + weapon.attackSpeedTicks (4 for the sword).
   - If the cooldown is NOT ready, the press is discarded (no queueing or buffering beyond that one tick).
   - Attacking (hit, miss or whiff) consumes the player's tick: no movement that tick, even if a direction is held.
   - The cooldown counts down every tick regardless of position or movement.
   - The whiff swing animation must look distinct from a real hit (e.g. a wider, faster sweep with a small white "whoosh" arc on the facing tile, and no hitsplat).
5. Eating unchanged: □ (button 2) / E. It consumes the tick (no move, no attack) and sets nextAttackTick = max(nextAttackTick, eatTick + 3). If attack and eat are both pressed in the same tick, eat wins.

## Wolves (OSRS NPC rules)
6. Dumb pathing, with NO BFS. Each tick a wolf that wants to reach the player takes at most ONE step using OSRS-style naive movement. Let sx = sign(player.x - wolf.x) and sz = sign(player.z - wolf.z).
   - First try the diagonal (sx, sz), if both are nonzero, the target tile is free and both corner tiles are walkable (same no-corner-cutting rule as the player).
   - Else try the x step (sx, 0) if sx != 0 and the tile is free.
   - Else try the z step (0, sz) if sz != 0 and the tile is free.
   - Else stay put.
   "Free" = walkable, not the player's tile, and not occupied by another wolf (including a wolf that already moved this tick). So wolves get stuck behind pillars (safespotting) and line up behind each other.
   - A wolf that is DIAGONALLY adjacent to the player must step to a cardinal-adjacent tile: try the x step, else the z step (never the diagonal, which would be the player's tile).
7. Melee range: 1, cardinal only.
8. Attack cycle (attack speed 3), resolved in the NPC phase of tick T, in spawn order:
   a. If the wolf is telegraphing (it committed to attacking at T on the previous tick), it ATTACKS now. If the player is cardinally adjacent at this moment (after the player's action this tick), roll hit/damage with a hitsplat. Otherwise it's a whiff: play the bite animation and log it, with no hitsplat. Either way: nextAttackTick = T + 3, telegraph off, and the wolf must not move on tick T+1 (waitUntilTick = T + 2).
   b. Else, if the player is cardinally adjacent: stand still. If nextAttackTick <= T + 1, start the telegraph (crouch + glow, visible for the whole interval until the next tick) so it attacks at T+1.
   c. Else (not in range): if T >= waitUntilTick, move one step per rule 6. After moving, if the wolf is now cardinally adjacent and nextAttackTick <= T + 1, start the telegraph.
   So a bite only ever lands on a tick right after a visible telegraph, and a player who steps out on the attack tick makes it whiff.
9. Tick order (document it in a comment block at the top of main.js): 1) player input (eat OR attack OR move, in that priority), 2) NPCs act in spawn order (rule 8), 3) resolve deaths and room state. Keep everything deterministic given the RNG seed.
10. Keep: 3 wolves, the 3-tick countdown, spawns in the north rows, room cleared / you died banners, restart on ✕/Space, pause, HP/food HUD, hitsplats, health bars, wolf death fade, the enemy def table (so mages/archers plug in at M3), weapon defs.
11. Controls hint: remove the target lines. Keyboard: "WASD move · Space attack (facing tile) · E eat · Esc pause". PS: "Left stick move · ✕ attack · □ eat · Options pause"; Xbox: A / X / Start. Keep the yellow <b> styling.
12. Title: "Rimefall — Milestone 2.1".

// ---- targeting ----

let targetId = null;

function distTo(e) {
  return Math.abs(e.x - player.x) + Math.abs(e.z - player.z);
}

function getTarget() {
  if (targetId == null) return null;
  const e = enemies.get(targetId);
  if (!e || !e.alive) return null;
  return e;
}

function clearTarget() {
  targetId = null;
}

function selectNearestTarget() {
  const living = enemies.living();
  if (living.length === 0) return false;

  let minD = Infinity;
  for (const e of living) minD = Math.min(minD, distTo(e));
  let pool = living.filter((e) => distTo(e) <= minD + 1);

  // Prefer enemies roughly in the facing direction when distances are close.
  const fx0 = player.facing.x;
  const fz0 = player.facing.z;
  const flen = Math.hypot(fx0, fz0) || 1;
  const front = pool.filter((e) => {
    const dx = e.x - player.x;
    const dz = e.z - player.z;
    const len = Math.hypot(dx, dz) || 1;
    return (dx * fx0 + dz * fz0) / (len * flen) > 0.45;
  });
  if (front.length > 0) pool = front;

  pool.sort((a, b) => distTo(a) - distTo(b) || a.uid - b.uid);
  targetId = pool[0].id;
  return true;
}

function cycleTarget(dir) {
  const living = enemies.living();
  if (living.length === 0) {
    clearTarget();
    return;
  }
  const order = living.slice().sort((a, b) => distTo(a) - distTo(b) || a.uid - b.uid);
  let idx = order.findIndex((e) => e.id === targetId);
  if (idx < 0) idx = dir > 0 ? -1 : 0;
  const n = order.length;
  idx = (idx + dir + n) % n;
  targetId = order[idx].id;
}

// ---- player movement (unchanged rules; enemies are extra walls) ----

function step(dx, dz) {
  const nx = player.x + dx;
  const nz = player.z + dz;
  if (!isWalkable(nx, nz)) return false;
  if (enemies.isOccupied(nx, nz)) return false;
  if (dx !== 0 && dz !== 0) {
    if (!isWalkable(player.x + dx, player.z)) return false;
    if (!isWalkable(player.x, player.z + dz)) return false;
    if (enemies.isOccupied(player.x + dx, player.z)) return false;
    if (enemies.isOccupied(player.x, player.z + dz)) return false;
  }
  player.x = nx;
  player.z = nz;
  return true;
}

// OSRS-like corner slide: a blocked diagonal falls back to a free cardinal
// component, trying the larger stick component first (x/east-west on a tie).
function tryMove(dx, dz, preferX) {
  if (dx !== 0 && dz !== 0) {
    if (step(dx, dz)) return { x: dx, z: dz };

    const first = preferX ? { x: dx, z: 0 } : { x: 0, z: dz };
    const second = preferX ? { x: 0, z: dz } : { x: dx, z: 0 };

    if (step(first.x, first.z)) return first;
    if (step(second.x, second.z)) return second;
    return null;
  }

  return step(dx, dz) ? { x: dx, z: dz } : null;
}

// ---- combat resolution ----

function playerAttackTick(tick) {
  if (targetId != null && !getTarget()) {
    clearTarget();
    return;
  }
  const target = getTarget();
  if (!target) return;
  if (tick < player.nextAttackTick) return;

  const weapon = player.weapon;
  if (!inWeaponRange(weapon, player.x, player.z, target.x, target.z)) return;

  player.facing = {
    x: Math.sign(target.x - player.x),
    z: Math.sign(target.z - player.z),
  };
  player.nextAttackTick = tick + weapon.attackSpeedTicks;
  render.triggerPlayerAttack();

  const hit = rollHit(rng, weapon.accuracy, target.defence);
  const dmg = hit ? rollDamage(rng, weapon.maxHit) : 0;

  if (hit) {
    target.hp = Math.max(0, target.hp - dmg);
    target.damageTick = tick;
  }

  fx.splat({ kind: 'enemy', id: target.id }, hit ? 'hit' : 'miss', String(dmg), tick);
  logEvent({
    tick,
    type: 'player_attack',
    src: 'player',
    dst: target.id,
    hit,
    dmg,
    x: target.x,
    z: target.z,
  });

  if (target.hp <= 0) {
    target.alive = false;
    target.deathTick = tick;
    target.telegraph = false;
    logEvent({
      tick,
      type: 'enemy_death',
      src: 'player',
      dst: target.id,
      hit: true,
      dmg: 0,
      x: target.x,
      z: target.z,
    });
    clearTarget();
  }
}

function handleEnemyBite(tick, wolf, hit, dmg) {
  if (hit) {
    player.hp = Math.max(0, player.hp - dmg);
    player.damageTick = tick;
    if (player.hp <= 0) {
      fatalWolfId = wolf.id;
      fatalDmg = dmg;
    }
  }
  fx.splat({ kind: 'player' }, hit ? 'hit' : 'miss', String(dmg), tick);
  logEvent({
    tick,
    type: 'enemy_attack',
    src: wolf.id,
    dst: 'player',
    hit,
    dmg,
    x: player.x,
    z: player.z,
  });
}

function restartRoom(seed) {
  clearTarget();
  room.restart(ticker.tick, seed);
  player.defence = PLAYER_STATS.defence;
  lastMoveDir = null;
  fatalWolfId = null;
  fatalDmg = 0;
}

// ---- the one game tick ----
// Order: input actions -> player move -> player attack -> enemies -> deaths ->
// room flow. Presentation never mutates logical state.

function gameTick(tick) {
  const fromX = player.x;
  const fromZ = player.z;
  player.prevX = fromX;
  player.prevZ = fromZ;
  player.moved = false;

  fatalWolfId = null;
  fatalDmg = 0;

  enemies.beginTick(tick);

  let ateThisTick = false;
  const actions = input.consumeActions();
  const busy = room.state === 'cleared' || room.state === 'dead';

  for (const action of actions) {
    if (busy) {
      if (action === 'attack') {
        restartRoom();
      } else if (action === 'clear') {
        clearTarget();
      }
      continue;
    }

    if (action === 'attack') {
      if (!getTarget()) selectNearestTarget();
      // Pressing again while targeting keeps the current target.
    } else if (action === 'cycle') {
      cycleTarget(1);
    } else if (action === 'cycleBack') {
      cycleTarget(-1);
    } else if (action === 'clear') {
      clearTarget();
    } else if (action === 'eat') {
      if (player.food <= 0) {
        showToast('No food left', 1400);
      } else if (player.hp >= player.maxHp) {
        showToast('Already at full health', 1400);
      } else {
        const heal = Math.min(PLAYER_STATS.foodHeal, player.maxHp - player.hp);
        player.food -= 1;
        player.hp += heal;
        player.nextAttackTick = Math.max(player.nextAttackTick, tick + 3);
        ateThisTick = true;
        fx.splat({ kind: 'player' }, 'heal', `+${heal}`, tick);
        logEvent({
          tick,
          type: 'eat',
          src: 'player',
          dst: 'player',
          hit: false,
          dmg: heal,
          x: player.x,
          z: player.z,
        });
      }
    }
  }

  // 1) movement (skipped on an eat tick and when dead)
  if (!ateThisTick && room.state !== 'dead') {
    // useMovement() has already been evaluated this frame, before the ticker ran.
    const intent = debugMove !== null ? debugMove : input.getMoveIntent();
    let actual = null;
    if (intent && intent.dir) {
      actual = tryMove(intent.dir.x, intent.dir.z, intent.preferX);
    }

    lastMoveDir = actual ? { x: actual.x, z: actual.z } : null;

    if (actual) {
      player.facing = { x: actual.x, z: actual.z };
      player.moved = true;
    }
  } else {
    lastMoveDir = null;
  }

  // 2) player attack: engaged targets are attacked whenever adjacent + ready
  if (room.state === 'fighting') {
    playerAttackTick(tick);
  }

  // 3) enemies move/attack, fixed order, with per-tick reservations
  if (room.state === 'fighting') {
    enemies.tick(tick, player, {
      isPlayerAlive: () => player.hp > 0,
      onBite: (wolf, hit, dmg) => handleEnemyBite(tick, wolf, hit, dmg),
    });

    if (player.hp <= 0) {
      room.playerDied(tick, fatalWolfId, fatalDmg);
      clearTarget();
    }
  }

  // 4) room flow: countdown steps, cleared detection
  room.tick(tick);

  moveLog.push({
    tick,
    fromX,
    fromZ,
    toX: player.x,
    toZ: player.z,
  });
  if (moveLog.length > MAX_MOVE_LOG) {
    moveLog.splice(0, moveLog.length - MAX_MOVE_LOG);
  }
}

ticker.subscribe((tick) => gameTick(tick));

function worldView() {
  return { enemies: enemies.list, targetId, tick: ticker.tick };
}

function stepTicks(count) {
  const n = Math.max(0, Math.floor(Number(count) || 0));
  for (let i = 0; i < n; i++) {
    ticker.tick += 1;
    gameTick(ticker.tick);
  }
  ticker.resync();
  render.update(0, player, 1, worldView());
}

// Styles are data-driven so ranged/magic weapons can plug in at M3.

  defence: 12,
  foodCount: 4,
  foodHeal: 10,

export const WEAPONS = {
  sword: {
    id: 'sword',
    name: 'Iron Sword',
    style: 'melee',
    attackSpeedTicks: 4,
    range: 1,
    maxHit: 6,
    accuracy: 18,

export function getWeapon(id) {
  return WEAPONS[id] || null;
}

let warnedNonFiniteRollHit = false;

// OSRS-like: attack roll vs defence roll, each uniform over [0, stat].
// A missing/non-finite stat is treated as zero so a single bad input can never
// turn the whole roll into NaN (which would make every attack silently miss).
export function rollHit(rng, accuracy, defence) {
  let attackStat = Number(accuracy);
  let defenceStat = Number(defence);

  if (!Number.isFinite(attackStat) || !Number.isFinite(defenceStat)) {
    if (!warnedNonFiniteRollHit) {
      warnedNonFiniteRollHit = true;
      console.warn('[rimefall] rollHit received a non-finite stat; treating it as 0.', {
        accuracy,
        defence,
      });
    }
    if (!Number.isFinite(attackStat)) attackStat = 0;
    if (!Number.isFinite(defenceStat)) defenceStat = 0;
  }

  const attackRoll = rng.next() * (attackStat + 1);
  const defenceRoll = rng.next() * (defenceStat + 1);
  return attackRoll > defenceRoll;
}

// Uniform integer 0..maxHit. A hit may roll 0 (shown as a red 0).
export function rollDamage(rng, maxHit) {
  return Math.floor(rng.next() * (maxHit + 1));
}

export function manhattan(ax, az, bx, bz) {
  return Math.abs(ax - bx) + Math.abs(az - bz);
}

// Melee reaches only cardinally adjacent tiles, never diagonals.
export function isCardinalAdjacent(ax, az, bx, bz) {
  return Math.abs(ax - bx) + Math.abs(az - bz) === 1;
}

export function inWeaponRange(weapon, ax, az, bx, bz) {
  const d = manhattan(ax, az, bx, bz);
  if (weapon.style === 'melee') return d === 1;
  return d <= weapon.range;
}

// Enemy definitions, spawning, fixed-order AI and BFS pathing.
// Wolves alternate bite/move on ticks and telegraph bites one tick ahead.

import { isWalkable } from './world.js';
import { rollHit, rollDamage, isCardinalAdjacent } from './combat.js';

export const ENEMY_DEFS = {
  ice_wolf: {
    id: 'ice_wolf',
    name: 'Ice Wolf',
    kind: 'ice_wolf',
    hp: 12,
    attackSpeedTicks: 3,
    range: 1,
    maxHit: 4,
    accuracy: 12,
    defence: 15,
    style: 'melee',
    scale: 1.12,
  },
};

const CARDINAL_STEPS = [
  [0, -1],
  [1, 0],
  [0, 1],
  [-1, 0],
];
const DIAGONAL_STEPS = [
  [1, -1],
  [1, 1],
  [-1, 1],
  [-1, -1],
];
const ALL_STEPS = [...CARDINAL_STEPS, ...DIAGONAL_STEPS];

function key(x, z) {
  return `${x},${z}`;
}

export class Enemies {
  constructor(rng) {
    this.rng = rng;
    this.list = [];
    this.nextUid = 1;
    this.reserved = new Set();
  }

  clear() {
    this.list = [];
    this.nextUid = 1;
    this.reserved.clear();
  }

  spawn(kind, x, z, tick) {
    const def = ENEMY_DEFS[kind];
    if (!def) throw new Error(`Unknown enemy kind: ${kind}`);
    const enemy = {
      id: `${kind}-${this.nextUid}`,
      uid: this.nextUid,
      kind,
      name: def.name,
      x,
      z,
      prevX: x,
      prevZ: z,
      hp: def.hp,
      maxHp: def.hp,
      alive: true,
      nextAttackTick: tick + 1,
      telegraph: false,
      deathTick: null,
      facing: { x: 0, z: 1 },
      damageTick: -9999,
      accuracy: def.accuracy,
      defence: def.defence,
      maxHit: def.maxHit,
      attackSpeedTicks: def.attackSpeedTicks,
      range: def.range,
      style: def.style,
    };
    this.nextUid += 1;
    this.list.push(enemy);
    return enemy;
  }

  get(id) {
    for (const e of this.list) {
      if (e.id === id) return e;
    }
    return null;
  }

  living() {
    return this.list.filter((e) => e.alive);
  }

  livingCount() {
    let n = 0;
    for (const e of this.list) if (e.alive) n += 1;
    return n;
  }

  isOccupied(x, z) {
    for (const e of this.list) {
      if (e.alive && e.x === x && e.z === z) return true;
    }
    return false;
  }

  // Called once at the top of every game tick, before any AI.
  // Stores interpolation origins and removes corpses that finished fading.
  beginTick(tick) {
    const next = [];
    for (const e of this.list) {
      if (!e.alive && e.deathTick != null && tick - e.deathTick >= 1) continue;
      e.prevX = e.x;
      e.prevZ = e.z;
      next.push(e);
    }
    this.list = next;
  }

  // Fixed order = list order. Bites resolve immediately; movement reservations
  // stop later wolves from entering the same destination this tick.
  tick(tick, player, ctx) {
    this.reserved.clear();

    for (const wolf of this.list) {
      if (!wolf.alive) continue;
      if (!ctx.isPlayerAlive()) break;

      const dx = player.x - wolf.x;
      const dz = player.z - wolf.z;
      const adjacent = isCardinalAdjacent(wolf.x, wolf.z, player.x, player.z);

      if (adjacent && wolf.nextAttackTick <= tick) {
        const hit = rollHit(this.rng, wolf.accuracy, player.defence);
        const dmg = hit ? rollDamage(this.rng, wolf.maxHit) : 0;
        wolf.nextAttackTick = tick + wolf.attackSpeedTicks;
        wolf.telegraph = false;
        wolf.facing = { x: Math.sign(dx), z: Math.sign(dz) };
        ctx.onBite(wolf, hit, dmg);
        continue;
      }

      if (!adjacent) {
        const next = this._findStep(wolf, player);
        if (next) {
          wolf.facing = { x: Math.sign(next.x - wolf.x), z: Math.sign(next.z - wolf.z) };
          wolf.x = next.x;
          wolf.z = next.z;
          this.reserved.add(key(next.x, next.z));
        }
      } else {
        wolf.facing = { x: Math.sign(dx), z: Math.sign(dz) };
      }

      const nowAdjacent = isCardinalAdjacent(wolf.x, wolf.z, player.x, player.z);
      wolf.telegraph = nowAdjacent && wolf.nextAttackTick <= tick + 1;
    }
  }

  // 8-way BFS to the closest free tile cardinally adjacent to the player.
  // Diagonals require both orthogonal corner tiles to be enterable (same rule
  // as the player's step()). Returns the first tile of the path, or null.
  _findStep(wolf, player) {
    if (isCardinalAdjacent(wolf.x, wolf.z, player.x, player.z)) return null;

    const blocked = new Set(this.reserved);
    blocked.add(key(player.x, player.z));
    for (const e of this.list) {
      if (e !== wolf && e.alive) blocked.add(key(e.x, e.z));
    }

    const startX = wolf.x;
    const startZ = wolf.z;
    const seen = new Set([key(startX, startZ)]);
    const queue = [{ x: startX, z: startZ, first: null }];
    let head = 0;

    while (head < queue.length) {
      const cur = queue[head];
      head += 1;

      for (const step of ALL_STEPS) {
        const nx = cur.x + step[0];
        const nz = cur.z + step[1];
        const k = key(nx, nz);
        if (seen.has(k)) continue;
        if (!isWalkable(nx, nz) || blocked.has(k)) continue;

        if (step[0] !== 0 && step[1] !== 0) {
          const sx = cur.x + step[0];
          const sz = cur.z + step[1];
          if (!isWalkable(sx, cur.z) || blocked.has(key(sx, cur.z))) continue;
          if (!isWalkable(cur.x, sz) || blocked.has(key(cur.x, sz))) continue;
        }

        seen.add(k);
        const first = cur.first || { x: nx, z: nz };
        if (isCardinalAdjacent(nx, nz, player.x, player.z)) return first;
        queue.push({ x: nx, z: nz, first });
      }
    }

    return null;
  }
}

// Room flow: countdown, wolf spawns, cleared state, death and restart.

import { SPAWN, isWalkable } from './world.js';

export const COUNTDOWN_TICKS = 3;
export const WOLF_COUNT = 3;
const SPAWN_ROWS = [1, 2];

export class Room {
  constructor(ctx) {
    // ctx: { rng, enemies, player, fx, log, noEnemies }
    this.ctx = ctx;
    this.state = 'countdown';
    this.countdownLeft = COUNTDOWN_TICKS;
    this.startedAtTick = 0;
    this.spawned = false;
  }

  start(tick) {
    this.startedAtTick = tick;
    this.countdownLeft = COUNTDOWN_TICKS;
    this.spawned = false;

    if (this.ctx.noEnemies) {
      this.state = 'fighting';
      return;
    }

    this.state = 'countdown';
    this.ctx.fx.banner('3', 'Ice wolves approach…', 560);
  }

  restart(tick, seed) {
    const { rng, enemies, player, fx, log } = this.ctx;

    if (seed !== undefined && seed !== null && Number.isFinite(Number(seed))) {
      rng.reset(Number(seed));
    }

    enemies.clear();

    player.x = SPAWN.x;
    player.z = SPAWN.z;
    player.prevX = SPAWN.x;
    player.prevZ = SPAWN.z;
    player.facing = { x: 0, z: 1 };
    player.moved = false;
    player.hp = player.maxHp;
    player.food = player.maxFood;
    player.nextAttackTick = 0;
    player.damageTick = -9999;

    fx.clearTransient();
    log({ tick, type: 'restart', src: 'player', dst: 'room', hit: false, dmg: 0, x: SPAWN.x, z: SPAWN.z });

    this.start(tick);
  }

  tick(tick) {
    // Do not consume a countdown step on the very tick a (re)start happened.
    if (tick === this.startedAtTick) return;

    if (this.state === 'countdown') {
      this.countdownLeft -= 1;
      if (this.countdownLeft <= 0) {
        this.state = 'fighting';
        this.spawnWolves(tick);
        this.ctx.fx.banner('Fight!', '', 900);
      } else {
        this.ctx.fx.banner(String(this.countdownLeft), '', 560);
      }
      return;
    }

    if (this.state === 'fighting' && this.spawned && !this.ctx.noEnemies) {
      if (this.ctx.enemies.livingCount() === 0) {
        this.state = 'cleared';
        const p = this.ctx.player;
        this.ctx.log({
          tick,
          type: 'room_cleared',
          src: 'room',
          dst: null,
          hit: false,
          dmg: 0,
          x: p.x,
          z: p.z,
        });
        this.ctx.fx.banner('Room cleared!', 'Press ✕ / Space to restart', 0);
      }
    }
  }

  playerDied(tick, src, dmg) {
    if (this.state === 'dead') return;
    this.state = 'dead';
    const p = this.ctx.player;
    this.ctx.log({
      tick,
      type: 'player_died',
      src: src || null,
      dst: 'player',
      hit: true,
      dmg: dmg || 0,
      x: p.x,
      z: p.z,
    });
    this.ctx.fx.banner('You died', 'Press ✕ / Space to restart', 0);
  }

  spawnWolves(tick) {
    const { rng, enemies, player, log } = this.ctx;

    const tiles = [];
    for (const z of SPAWN_ROWS) {
      for (let x = 1; x <= 13; x++) {
        if (!isWalkable(x, z)) continue;
        if (x === player.x && z === player.z) continue;

      if (spread) chosen.push(t);
    }
    for (const t of tiles) {
      if (chosen.length >= WOLF_COUNT) break;
      if (!chosen.includes(t)) chosen.push(t);

    for (const t of chosen) {
      const enemy = enemies.spawn('ice_wolf', t.x, t.z, tick);

        tick,
        type: 'spawn',
        src: 'room',
        dst: enemy.id,
        hit: false,
        dmg: 0,
        x: t.x,
        z: t.z,
      });
    }

    this.spawned = chosen.length > 0;
  }

// Unified keyboard + standard-gamepad input.
// Movement maps directly to grid directions because the camera faces north.
// Stick processing runs every frame with persistent hysteresis state.

const KEY_DIR = {
  KeyW: [0, -1], ArrowUp: [0, -1],
  KeyS: [0, 1], ArrowDown: [0, 1],
  KeyA: [-1, 0], ArrowLeft: [-1, 0],
  KeyD: [1, 0], ArrowRight: [1, 0],
};

const KEY_ACTION = {
  Space: 'attack',
  KeyE: 'eat',
  KeyQ: 'clear',
  Digit1: 'swap1', Digit2: 'swap2', Digit3: 'swap3',
  Numpad1: 'swap1', Numpad2: 'swap2', Numpad3: 'swap3',
};

// Standard mapping buttons. D-pad is action-only; it never moves the player.
// 0 ✕/A attack · 1 ○/B clear · 2 □/X eat · 5 R1/RB cycle · 4 L1/LB cycle back
const PAD_ACTION = {
  0: 'attack',
  1: 'clear',
  2: 'eat',
  4: 'cycleBack',
  5: 'cycle',
  14: 'swap1', 12: 'swap2', 15: 'swap3',
};
const PAD_PAUSE_BUTTON = 9;

export const STICK_DEADZONE = 0.35;
export const STICK_RELEASE_DEADZONE = 0.25;

const STICK_ACTIVITY_DELTA = 0.08;
const TAU = Math.PI * 2;
const CARDINAL_HALF_WIDTH = (Math.PI * 35) / 180; // 70-degree cardinals
const DIAGONAL_HALF_WIDTH = Math.PI / 18;         // diagonals only within 10 degrees
const DIRECTION_HYSTERESIS = Math.PI / 15;        // 12 degrees past a boundary

const DIRECTIONS = [
  { x: 0, z: -1, angle: 0, halfAngle: CARDINAL_HALF_WIDTH, diagonal: false },
  { x: 1, z: -1, angle: Math.PI / 4, halfAngle: DIAGONAL_HALF_WIDTH, diagonal: true },
  { x: 1, z: 0, angle: Math.PI / 2, halfAngle: CARDINAL_HALF_WIDTH, diagonal: false },
  { x: 1, z: 1, angle: (3 * Math.PI) / 4, halfAngle: DIAGONAL_HALF_WIDTH, diagonal: true },
  { x: 0, z: 1, angle: Math.PI, halfAngle: CARDINAL_HALF_WIDTH, diagonal: false },
  { x: -1, z: 1, angle: (5 * Math.PI) / 4, halfAngle: DIAGONAL_HALF_WIDTH, diagonal: true },
  { x: -1, z: 0, angle: (3 * Math.PI) / 2, halfAngle: CARDINAL_HALF_WIDTH, diagonal: false },
  { x: -1, z: -1, angle: (7 * Math.PI) / 4, halfAngle: DIAGONAL_HALF_WIDTH, diagonal: true },
];

function normalizeAngle(a) {
  a %= TAU;
  return a < 0 ? a + TAU : a;
}

function angleDistance(a, b) {
  const d = Math.abs(normalizeAngle(a) - normalizeAngle(b));
  return Math.min(d, TAU - d);
}

function signedAngleDifference(a, b) {
  let d = normalizeAngle(a) - normalizeAngle(b);
  if (d > Math.PI) d -= TAU;
  if (d <= -Math.PI) d += TAU;
  return d;
}

function directionInfo(x, z) {
  for (const dir of DIRECTIONS) {
    if (dir.x === x && dir.z === z) return dir;
  }
  return null;
}

/**
 * Pure angle -> grid-direction snapping.
 * 0 = north/up, PI/2 = east/right, PI = south/down, 3PI/2 = west/left.
 * Cardials own 70-degree sectors; diagonals exist only within 10 degrees of
 * 45/135/225/315.
 */
export function pickGridDir(angle) {
  if (typeof angle !== 'number' || !Number.isFinite(angle)) return null;

  const a = normalizeAngle(angle);
  let bestDiagonal = null;
  let bestDiagonalDist = Infinity;
  let bestCardinal = null;
  let bestCardinalDist = Infinity;

  for (const dir of DIRECTIONS) {
    const dist = angleDistance(a, dir.angle);
    if (dir.diagonal) {
      if (dist < bestDiagonalDist) {
        bestDiagonalDist = dist;
        bestDiagonal = dir;
      }
    } else if (dist < bestCardinalDist) {
      bestCardinalDist = dist;
      bestCardinal = dir;
    }
  }

  const chosen =
    bestDiagonal && bestDiagonalDist <= DIAGONAL_HALF_WIDTH + 1e-9
      ? bestDiagonal
      : bestCardinal;

  return chosen ? { x: chosen.x, z: chosen.z } : null;
}

export class Input {
  constructor(hooks = {}) {
    this.onPause = hooks.onPause || (() => {});
    this.onToast = hooks.onToast || (() => {});

    this.device = 'keyboard';
    this.keys = new Set();
    this.actions = [];

    this.padAxes = { x: 0, y: 0 };
    this.padButtonState = new Map();
    this.connectedIds = new Set();
    this.notifiedIds = new Set();

    this.stickHeld = null;    // persistent snapped stick direction
    this.heldDir = null;      // final current direction for this frame
    this.currentIntent = null;

    this._padStickActive = false;
    this._activePadId = null;

    this._bindKeyboard();

    const poll = () => this.pollGamepads();
    window.addEventListener('gamepadconnected', poll);
    window.addEventListener('gamepaddisconnected', poll);
  }

  _bindKeyboard() {
    window.addEventListener('keydown', (e) => {
      if (e.code === 'Escape') {
        e.preventDefault();
        if (!e.repeat) {
          this.device = 'keyboard';
          this.onPause();
        }
        return;
      }

      if (e.code === 'Tab') {
        e.preventDefault();
        if (!e.repeat) {
          this.device = 'keyboard';
          this.actions.push(e.shiftKey ? 'cycleBack' : 'cycle');
        }
        return;
      }

      if (KEY_DIR[e.code]) {
        e.preventDefault();
        if (!e.repeat) this.device = 'keyboard';
        this.keys.add(e.code);
        return;
      }

      const action = KEY_ACTION[e.code];
      if (action) {
        e.preventDefault();
        if (!e.repeat) {
          this.device = 'keyboard';
          this.actions.push(action);
        }
      }
    });

    window.addEventListener('keyup', (e) => {
      if (KEY_DIR[e.code]) this.keys.delete(e.code);
    });

    // Avoid "stuck" keys when the window loses focus.
    window.addEventListener('blur', () => this.keys.clear());
  }

  keyboardDir() {
    let x = 0;
    let z = 0;
    for (const code of this.keys) {
      const d = KEY_DIR[code];
      if (!d) continue;
      x += d[0];
      z += d[1];
    }
    x = Math.sign(x);
    z = Math.sign(z);
    if (!x && !z) return null;
    return { x, z };
  }

  // Persistent stick snapping + deadzone/hysteresis, evaluated every frame.
  _updateStickHeld() {
    const ax = Number.isFinite(this.padAxes.x) ? this.padAxes.x : 0;
    const ay = Number.isFinite(this.padAxes.y) ? this.padAxes.y : 0;
    const magnitude = Math.hypot(ax, ay);

    if (this.stickHeld) {
      if (magnitude < STICK_RELEASE_DEADZONE) {
        this.stickHeld = null;
        return;
      }

      const angle = Math.atan2(ax, -ay);
      const delta = signedAngleDifference(angle, this.stickHeld.angle);

      // Keep the held direction until the angle passes more than 12 degrees
      // beyond its sector boundary, then snap to the sector it is in.
      if (Math.abs(delta) > this.stickHeld.halfAngle + DIRECTION_HYSTERESIS + 1e-9) {
        const next = pickGridDir(angle);
        if (next) {
          const info = directionInfo(next.x, next.z);
          if (info) this.stickHeld = info;
        }
      }
      return;
    }

    if (magnitude >= STICK_DEADZONE) {
      const angle = Math.atan2(ax, -ay);
      const next = pickGridDir(angle);
      if (next) this.stickHeld = directionInfo(next.x, next.z);
    }
  }

  // Called once per rendered frame, after pollGamepads and before ticker.update.
  updateMovement() {
    this._updateStickHeld();

    const kb = this.keyboardDir();
    const padDevice = this.device.startsWith('gamepad');
    let dir = null;
    let source = null;

    if (padDevice) {
      if (this.stickHeld) {
        dir = this.stickHeld;
        source = 'stick';
      } else if (kb) {
        dir = kb;
        source = 'keyboard';
      }
    } else {
      if (kb) {
        dir = kb;
        source = 'keyboard';
      } else if (this.stickHeld) {
        dir = this.stickHeld;
        source = 'stick';
      }
    }

    let preferX = true;
    if (dir && source === 'stick' && dir.x !== 0 && dir.z !== 0) {
      preferX = Math.abs(this.padAxes.x) >= Math.abs(this.padAxes.y);
    }

    this.heldDir = dir ? { x: dir.x, z: dir.z } : null;
    this.currentIntent = dir
      ? {
          dir: { x: dir.x, z: dir.z },
          preferX,
          source,
        }
      : null;
  }

  getDirection() {
    return this.heldDir ? { x: this.heldDir.x, z: this.heldDir.z } : null;
  }

  getMoveIntent() {
    return this.currentIntent;
  }

  consumeActions() {
    const queued = this.actions;
    this.actions = [];
    return queued;
  }

  // Used by the automated test hooks: identical to a real button press.
  queueAction(action) {
    if (action) this.actions.push(action);
  }

  pollGamepads() {
    if (typeof navigator === 'undefined' || !navigator.getGamepads) {
      this.padAxes = { x: 0, y: 0 };
      this._padStickActive = false;
      this._activePadId = null;
      return;
    }

    const pads = navigator.getGamepads();
    if (!pads) {
      this.padAxes = { x: 0, y: 0 };
      this._padStickActive = false;
      this._activePadId = null;
      return;
    }

    const seen = new Set();
    const candidates = [];

    for (let i = 0; i < pads.length; i++) {
      const gp = pads[i];
      if (!gp || !gp.connected) {
        this.padButtonState.delete(i);
        continue;
      }

      seen.add(gp.id);

      if (!this.connectedIds.has(gp.id)) {
        this.connectedIds.add(gp.id);
        if (!this.notifiedIds.has(gp.id)) {
          this.notifiedIds.add(gp.id);
          this.onToast(`🎮 Controller connected: ${gp.id}`);
        }
      }

      const buttons = gp.buttons || [];
      let prev = this.padButtonState.get(i);
      if (!prev || prev.length !== buttons.length) {
        prev = new Array(buttons.length).fill(false);
        this.padButtonState.set(i, prev);
      }

      // Face buttons and D-pad. D-pad queues swaps only; it never moves.
      for (const key of Object.keys(PAD_ACTION)) {
        const idx = Number(key);
        const btn = buttons[idx];
        const pressed = !!(btn && btn.pressed);
        if (pressed && !prev[idx]) {
          this.device = `gamepad: ${gp.id}`;
          this.actions.push(PAD_ACTION[idx]);
        }
        prev[idx] = pressed;
      }

      const pauseBtn = buttons[PAD_PAUSE_BUTTON];
      const pausePressed = !!(pauseBtn && pauseBtn.pressed);
      if (pausePressed && !prev[PAD_PAUSE_BUTTON]) {
        this.device = `gamepad: ${gp.id}`;
        this.onPause();
      }
      prev[PAD_PAUSE_BUTTON] = pausePressed;

      const axes = gp.axes || [];
      const ax = axes.length > 0 ? (axes[0] || 0) : 0;
      const ay = axes.length > 1 ? (axes[1] || 0) : 0;
      candidates.push({
        id: gp.id,
        ax,
        ay,
        magnitude: Math.hypot(ax, ay),
      });
    }

    const previousAx = this.padAxes.x;
    const previousAy = this.padAxes.y;
    const activeThreshold = this.stickHeld
      ? STICK_RELEASE_DEADZONE
      : STICK_DEADZONE;

    let chosen = null;
    if (this._activePadId !== null) {
      const active = candidates.find((c) => c.id === this._activePadId);
      if (active && active.magnitude >= activeThreshold) chosen = active;
    }

    if (!chosen) {
      let best = null;
      for (const c of candidates) {
        if (c.magnitude < STICK_DEADZONE) continue;
        if (!best || c.magnitude > best.magnitude) best = c;
      }
      chosen = best;
    }

    if (chosen) {
      this.padAxes = { x: chosen.ax, y: chosen.ay };

      const changedPad = this._activePadId !== chosen.id;
      this._activePadId = chosen.id;

      const threshold = this.stickHeld
        ? STICK_RELEASE_DEADZONE
        : STICK_DEADZONE;
      const active = chosen.magnitude >= threshold;
      const delta = Math.hypot(chosen.ax - previousAx, chosen.ay - previousAy);

      // Only actual new stick activity steals the input device. Holding a
      // steady stick does not override a more recent keyboard press.
      if (active && (!this._padStickActive || changedPad || delta > STICK_ACTIVITY_DELTA)) {
        this.device = `gamepad: ${chosen.id}`;
      }
      this._padStickActive = active;
    } else {
      this.padAxes = { x: 0, y: 0 };
      this._padStickActive = false;
      this._activePadId = null;
    }

    for (const id of Array.from(this.connectedIds)) {
      if (!seen.has(id)) {
        this.connectedIds.delete(id);
        this.onToast('Controller disconnected');
        if (this.device === `gamepad: ${id}`) this.device = 'keyboard';
        if (this._activePadId === id) {
          this._padStickActive = false;
          this._activePadId = null;
          this.padAxes = { x: 0, y: 0 };
        }
      }
    }
  }

function mulberry32(seed) {
  return function random() {
    seed |= 0;
    seed = (seed + 0x6d2b79f5) | 0;
    let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };

  _createSnowTexture() {
    // Soft round flake: white core fading to transparent, no external files.
    const size = 64;
    const canvas = document.createElement('canvas');
    canvas.width = size;
    canvas.height = size;
    const ctx = canvas.getContext('2d');
    const grad = ctx.createRadialGradient(size / 2, size / 2, 0, size / 2, size / 2, size / 2);
    grad.addColorStop(0, 'rgba(255,255,255,1)');
    grad.addColorStop(0.3, 'rgba(255,255,255,0.92)');
    grad.addColorStop(0.65, 'rgba(255,255,255,0.35)');
    grad.addColorStop(1, 'rgba(255,255,255,0)');
    ctx.fillStyle = grad;
    ctx.fillRect(0, 0, size, size);

    const tex = new THREE.CanvasTexture(canvas);
    tex.colorSpace = THREE.SRGBColorSpace;
    tex.needsUpdate = true;
    return tex;
  }

  _buildSnow() {
    this._snowRand = mulberry32(99);
    this._snowScratch = { x: 0, y: 0, z: 0 };
    this.snowTime = 0;

    const sprite = this._createSnowTexture();
    // Three size buckets give gentle per-flake variation without a custom shader.
    const layers = [
      { count: 250, size: 0.07 },
      { count: 350, size: 0.095 },
      { count: 300, size: 0.12 },
    ];

    this.snowLayers = [];
    for (const cfg of layers) {
      const positions = new Float32Array(cfg.count * 3);
      const speeds = new Float32Array(cfg.count);
      const phases = new Float32Array(cfg.count);
      const spawn = { x: 0, y: 0, z: 0 };

      for (let i = 0; i < cfg.count; i++) {
        this._spawnSnowPoint(spawn);
        const i3 = i * 3;
        positions[i3] = spawn.x;
        positions[i3 + 1] = spawn.y;
        positions[i3 + 2] = spawn.z;
        speeds[i] = 0.45 + this._snowRand() * 0.9;
        phases[i] = this._snowRand() * Math.PI * 2;
      }

      const geo = new THREE.BufferGeometry();
      geo.setAttribute('position', new THREE.BufferAttribute(positions, 3));

      const mat = new THREE.PointsMaterial({
        map: sprite,
        color: 0xffffff,
        size: cfg.size,
        sizeAttenuation: true,
        transparent: true,
        opacity: 0.8,
        depthWrite: false,
        alphaTest: 0.01,
      });

      const points = new THREE.Points(geo, mat);
      points.frustumCulled = false;
      this.scene.add(points);

      this.snowLayers.push({
        attr: geo.attributes.position,
        positions,
        speeds,
        phases,
        count: cfg.count,
      });
    }
  }

  _spawnSnowPoint(out) {
    const cam = this.camera.position;
    for (let attempt = 0; attempt < 8; attempt++) {
      out.x = SNOW_BOUNDS.minX + this._snowRand() * SNOW_WIDTH_X;
      out.y = SNOW_BOUNDS.minY + this._snowRand() * SNOW_HEIGHT;
      out.z = SNOW_BOUNDS.minZ + this._snowRand() * SNOW_WIDTH_Z;
      const dx = out.x - cam.x;
      const dy = out.y - cam.y;
      const dz = out.z - cam.z;
      if (dx * dx + dy * dy + dz * dz > SNOW_SAFE_RADIUS_SQ) return;
    }
    // Very unlikely fallback: a spot across the room from the camera.
    out.x = CENTER - 3;
    out.y = 3.5;
    out.z = CENTER - 3;
  }

  _projectToScreen(v) {
    const el = this.renderer.domElement;
    const w = el.clientWidth || window.innerWidth;
    const h = el.clientHeight || window.innerHeight;
    this.camera.updateMatrixWorld();
    this._tmpScreen.copy(v).project(this.camera);
    return {
      x: (this._tmpScreen.x * 0.5 + 0.5) * w,
      y: (-this._tmpScreen.y * 0.5 + 0.5) * h,
    };
  }

  tileToScreen(x, z) {
    this._tmpProj.set(x, 0, z);
    return this._projectToScreen(this._tmpProj);
  }

  // Project a live, interpolated entity anchor for DOM overlays.
  // ref = { kind: 'player' } or { kind: 'enemy', id }
  entityScreen(ref, yOffset = 1.2) {
    let mesh = null;
    if (ref && ref.kind === 'player') mesh = this.playerMesh;
    else if (ref && ref.kind === 'enemy') {
      const rec = this.enemyMeshes.get(ref.id);
      mesh = rec ? rec.mesh : null;
    }
    if (!mesh) return null;
    this._tmpProj.set(mesh.position.x, yOffset, mesh.position.z);
    const scr = this._projectToScreen(this._tmpProj);
    if (this._tmpScreen.z > 1 || this._tmpScreen.z < -1) return null;
    return scr;
  }

  _syncEnemies(list) {
    const seen = new Set();
    for (const e of list) {
      seen.add(e.id);
      let rec = this.enemyMeshes.get(e.id);
      if (!rec) {
        const mesh = createEntityMesh(e.kind);
        mesh.scale.setScalar(WOLF_SCALE);
        mesh.position.set(e.x, 0, e.z);
        this.scene.add(mesh);
        const mats = [];
        mesh.traverse((o) => {
          if (o.isMesh && o.material) mats.push(o.material);
        });
        rec = { mesh, mats, baseScale: WOLF_SCALE, crouch: 1 };
        this.enemyMeshes.set(e.id, rec);
      }
      rec.enemy = e;
    }

    for (const [id, rec] of Array.from(this.enemyMeshes.entries())) {
      if (seen.has(id)) continue;
      this.scene.remove(rec.mesh);
      rec.mesh.traverse((o) => {
        if (o.isMesh) {
          if (o.geometry) o.geometry.dispose();
          if (o.material) o.material.dispose();
        }
      });
      this.enemyMeshes.delete(id);
    }
  }

  // player: { x, z, prevX, prevZ, facing: {x,z} }
  // alpha: 0..1 progress through the current tick, straight from the ticker.
  // world: { enemies, targetId, tick } (optional combat presentation state)
  update(dt, player, alpha, world = null) {
    const clamped = Number.isFinite(dt) ? Math.max(0, Math.min(dt, 0.1)) : 0;
    const t = Math.min(1, Math.max(0, alpha));

    this.animTime += clamped;

    // The player mesh is exactly the linear interpolation of the previous and
    // current logical tiles. No pre-glide, easing, return glide or catch-up.
    const x = player.prevX + (player.x - player.prevX) * t;
    const z = player.prevZ + (player.z - player.prevZ) * t;
    this.playerMesh.position.set(x, 0, z);

    // Turn toward the actual move direction; when idle keep the last facing.
    const targetYaw = Math.atan2(player.facing.x, player.facing.z);
    let delta = targetYaw - this.playerMesh.rotation.y;
    delta = Math.atan2(Math.sin(delta), Math.cos(delta));
    this.playerMesh.rotation.y += delta * (1 - Math.exp(-18 * clamped));

    // Short procedural lunge on a child group; never touches the logical tile.
    const body = this.playerMesh.userData.body;
    if (body) {
      if (this.swing > 0) {
        this.swing = Math.max(0, this.swing - clamped);
        const p = 1 - this.swing / PLAYER_SWING_TIME;
        const arc = Math.sin(Math.min(1, Math.max(0, p)) * Math.PI);
        body.position.z = arc * 0.3;
        body.position.y = arc * 0.04;
        body.rotation.x = -arc * 0.14;
        body.rotation.y = Math.sin(p * Math.PI * 2) * 0.2 * (1 - p);
      } else {
        body.position.z = 0;
        body.position.y = 0;
        body.rotation.x = 0;
        body.rotation.y = 0;
      }
    }

    // True-tile marker snaps to the logical tile; it never interpolates.
    this.tileMarker.position.set(player.x, 0.035, player.z);

    // ---- enemies ----
    const list = world && world.enemies ? world.enemies : [];
    this._syncEnemies(list);
    const tick = world && Number.isFinite(world.tick) ? world.tick : 0;

    for (const rec of this.enemyMeshes.values()) {
      const e = rec.enemy;
      if (!e) continue;
      const mesh = rec.mesh;

      const ex = e.prevX + (e.x - e.prevX) * t;
      const ez = e.prevZ + (e.z - e.prevZ) * t;
      mesh.position.set(ex, 0, ez);

      const yaw = Math.atan2(e.facing.x, e.facing.z);
      let ed = yaw - mesh.rotation.y;
      ed = Math.atan2(Math.sin(ed), Math.cos(ed));
      mesh.rotation.y += ed * (1 - Math.exp(-16 * clamped));

      const tele = !!e.telegraph && e.alive;
      const crouchTarget = tele ? 0.78 : 1;
      if (clamped > 0) {
        rec.crouch += (crouchTarget - rec.crouch) * (1 - Math.exp(-22 * clamped));
      } else {
        rec.crouch = crouchTarget;
      }

      let fade = 0;
      if (!e.alive && e.deathTick != null) {
        fade = Math.min(1, Math.max(0, tick - e.deathTick + t));
      }

      const s = rec.baseScale * (1 - 0.55 * fade);
      mesh.scale.set(s, s * rec.crouch * (1 - 0.25 * fade), s);
      mesh.visible = fade < 1;

      for (const m of rec.mats) {
        if (fade > 0) {
          m.transparent = true;
          m.opacity = 1 - fade;
        } else if (m.opacity !== 1) {
          m.opacity = 1;
          m.transparent = false;
        }
        if (m.emissive) {
          if (tele) {
            m.emissive.setHex(0x3fa9ff);
            m.emissiveIntensity = 0.55 + 0.45 * Math.sin(this.animTime * 16);
          } else {
            m.emissiveIntensity = 0;
          }
        }
      }
    }

    // ---- target marker ----
    const targetId = world ? world.targetId : null;
    const targetRec = targetId != null ? this.enemyMeshes.get(targetId) : null;
    if (targetRec && targetRec.enemy && targetRec.enemy.alive) {
      this.targetRing.visible = true;
      this.targetRing.position.set(targetRec.mesh.position.x, 0.05, targetRec.mesh.position.z);
      const pulse = 1 + Math.sin(this.animTime * 5) * 0.06;
      this.targetRing.scale.setScalar(pulse);

      this.targetArrow.visible = true;
      const bob = Math.sin(this.animTime * 3.8) * 0.09;
      this.targetArrow.position.set(
        targetRec.mesh.position.x,
        2.35 + bob,
        targetRec.mesh.position.z
      );
    } else {
      this.targetRing.visible = false;
      this.targetArrow.visible = false;
    }

    // Camera glides toward the rendered player position.
    this.follow.lerp(this._tmpA.set(x, 0, z), 1 - Math.exp(-14 * clamped));
    this._tmpB.copy(this.follow).add(this.camOffset);
    this.camPos.lerp(this._tmpB, 1 - Math.exp(-6 * clamped));
    this.camera.position.copy(this.camPos);
    this.camLook.set(this.follow.x, 0.9, this.follow.z);
    this.camera.lookAt(this.camLook);

    // Drifting, swaying snow. Recycle anything that comes too close to the camera.
    this.snowTime += clamped;
    const camX = this.camera.position.x;
    const camY = this.camera.position.y;
    const camZ = this.camera.position.z;
    const out = this._snowScratch;

    for (const layer of this.snowLayers) {
      const p = layer.positions;
      for (let i = 0; i < layer.count; i++) {
        const i3 = i * 3;
        const phase = layer.phases[i];
        let sx = p[i3] + Math.sin(this.snowTime * 0.8 + phase) * 0.16 * clamped;
        let sy = p[i3 + 1] - layer.speeds[i] * clamped;
        let sz = p[i3 + 2] + Math.cos(this.snowTime * 0.65 + phase * 1.7) * 0.11 * clamped;

        if (sy < SNOW_BOUNDS.minY) sy += SNOW_HEIGHT;
        if (sx < SNOW_BOUNDS.minX) sx += SNOW_WIDTH_X;
        else if (sx > SNOW_BOUNDS.maxX) sx -= SNOW_WIDTH_X;
        if (sz < SNOW_BOUNDS.minZ) sz += SNOW_WIDTH_Z;
        else if (sz > SNOW_BOUNDS.maxZ) sz -= SNOW_WIDTH_Z;

        const dx = sx - camX;
        const dy = sy - camY;
        const dz = sz - camZ;
        if (dx * dx + dy * dy + dz * dz < SNOW_SAFE_RADIUS_SQ) {
          this._spawnSnowPoint(out);
          sx = out.x;
          sy = out.y;
          sz = out.z;
        }

        p[i3] = sx;
        p[i3 + 1] = sy;
        p[i3 + 2] = sz;
      }
      layer.attr.needsUpdate = true;
    }
  }

  render() {
    this.renderer.render(this.scene, this.camera);
  }

  resize() {
    const w = window.innerWidth;
    const h = window.innerHeight;
    this.camera.aspect = w / h;
    this.camera.updateProjectionMatrix();
    this.renderer.setSize(w, h);
  }

import * as THREE from 'three';

function material(color, opts = {}) {
  return new THREE.MeshStandardMaterial({
    color,
    flatShading: true,
    roughness: 0.88,
    metalness: 0.04,
    ...opts,
  });
}

function box(w, h, d, color, x = 0, y = 0, z = 0) {
  const mesh = new THREE.Mesh(new THREE.BoxGeometry(w, h, d), material(color));
  mesh.position.set(x, y, z);
  mesh.castShadow = true;
  mesh.receiveShadow = true;
  return mesh;
}

function cyl(rTop, rBottom, h, color, segments = 8) {
  const mesh = new THREE.Mesh(new THREE.CylinderGeometry(rTop, rBottom, h, segments), material(color));
  mesh.castShadow = true;
  mesh.receiveShadow = true;
  return mesh;
}

function buildPlayer(group) {

export function createEntityMesh(kind) {
  const group = new THREE.Group();
  if (kind === 'player') buildPlayer(group);
  else if (kind === 'ice_wolf') buildIceWolf(group);
  else if (kind === 'pillar') buildPillar(group);
  else if (kind === 'wall') buildWall(group);
  else throw new Error(`Unknown entity kind: ${kind}`);
  group.userData.kind = kind;
  return group;
}

// Static, deterministic room layout for Rimefall (15x15 tiles).
// Tile coords are integers 0..14; world position of a tile is (x, 0, z).

export const ROOM_SIZE = 15;
export const MIN = 0;
export const MAX = ROOM_SIZE - 1; // 14
export const SPAWN = { x: 7, z: 7 };

// Six broken ruin pillars, one tile each.
export const pillars = [
  { x: 3, z: 3 },
  { x: 11, z: 3 },
  { x: 3, z: 11 },
  { x: 11, z: 11 },
  { x: 5, z: 7 },
  { x: 9, z: 4 },
];

// A two-tile collapsed wall section.
export const brokenWall = [
  { x: 9, z: 9 },
  { x: 10, z: 9 },
];

// Every impassable interior tile, with its visual kind (used by the renderer).
export const blockers = [
  ...pillars.map((p) => ({ x: p.x, z: p.z, kind: 'pillar' })),
  ...brokenWall.map((p) => ({ x: p.x, z: p.z, kind: 'wall' })),
];

const blockedTiles = new Set(blockers.map((b) => `${b.x},${b.z}`));

// Perimeter ring (x/z 0 and 14) is wall; interior props block too.
export function isWalkable(x, z) {
  if (!Number.isInteger(x) || !Number.isInteger(z)) return false;
  if (x < MIN + 1 || x > MAX - 1 || z < MIN + 1 || z > MAX - 1) return false;
  return !blockedTiles.has(`${x},${z}`);
}
